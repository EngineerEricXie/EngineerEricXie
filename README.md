## About Me

I am interested in computational engineering systems that connect geometry, physics, and numerical simulation. My current work explores hexahedral mesh generation, finite element simulation, and practical tools for scientific computing workflows.

- Building: mesh generation and simulation experiments
- Learning: numerical methods, geometry processing, and high-performance computing
- Interested in: FEM, CAD/CAE pipelines, computational mechanics, and simulation software
- Goal: turn complex engineering ideas into reliable, understandable tools
